# Конвертер валют

Автономный Laravel-интерфейс для фиатных и криптовалютных конвертаций.

- фиатные курсы по умолчанию — НБРБ;
- курсы криптовалют по умолчанию — публичный API Kraken; CoinGecko доступен как альтернативный источник;
- SQLite хранит только последние курсы в `exchange_rates` для работы офлайн;
- UI — Blade, Alpine.js и Tailwind CSS.

В приложении нет аккаунтов, сессий, очередей, почты, файлового хранилища и фоновых задач.

## Источники курсов

В нижней панели откройте настройки провайдеров, чтобы выбрать источник отдельно
для каталога валют, курсов, дневных изменений и графиков. Для дневных изменений
и графиков настройки разделены на фиат и криптовалюты: провайдеры поддерживают
разные типы данных. В автоматическом режиме приложение выбирает совместимый
источник по приоритету: НБРБ для фиатных курсов/истории, Kraken для crypto
rates/market data, CoinGecko перед Kraken для совместимых crypto catalog/daily
changes. Выбор сохраняется локально в базе данных этого экземпляра приложения.
При ошибке выбранного вручную источника автоматического переключения на другой нет.

Сейчас доступны только встроенные источники. Пользовательские endpoint-адреса
и API-ключи пока не предусмотрены. Каталог может дополнительно использовать
метаданные других встроенных провайдеров для связи валют с их rate-adapters;
выбранный источник определяет, какие валюты входят в каталог.

```bash
composer install
npm install
php artisan migrate
npm run dev
php artisan serve
```

Проверка:

```bash
php artisan test
npm run build
```

## Android release

NativePHP-команды выполняются из Windows PowerShell, не из WSL. Перед
сборкой перенеси значения из `.env.native-release.example` в локальный
`.env`. Пароли подписи и путь к keystore не хранятся в `.env` — передавай их
только через переменные текущей PowerShell-сессии.

`config/nativephp.php` удаляет из runtime bundle `APP_KEY` и Android signing
variables, а также исключает тестовые и локальные файлы. NativePHP создаёт
свой per-device application key при первом запуске.

После изменения версии или кода приложения собирай APK так:

```powershell
php artisan native:package android --output=.\builds
```

Перед распространением проверь, что в APK не находятся `APP_KEY`,
`ANDROID_KEYSTORE_*`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`, а в
manifest указаны ожидаемые название и версия.
