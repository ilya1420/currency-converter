# Конвертер валют

Автономный Laravel-интерфейс для фиатных и криптовалютных конвертаций.

Свежесть официального курса НБРБ определяется датой действия в часовом
поясе Europe/Minsk: сегодняшний курс используется без повторного запроса,
в том числе при ручном обновлении. Дата другого дня требует проверки API.
Для записей без даты действия и рыночных курсов действует ограничение по
времени получения. Сохранённый курс и отсутствие сети — не одно и то же:
API отдельно сообщает `isFallback`, `fallbackReasons` и `rateDates`.
Общая дата обновления отражает самый старый из показанных курсов.

Длинные списки валют отправляются пакетами до 20 элементов. Обновление
одной пары внутри серверного запроса выполняется один раз; повреждённые
или неположительные курсы отклоняются как ошибка источника.

- фиатные курсы по умолчанию — НБРБ;
- курсы криптовалют по умолчанию — публичный API Kraken; CoinGecko доступен как альтернативный источник;
- SQLite хранит только последние курсы в `exchange_rates` для работы офлайн;
- UI — Blade, Alpine.js и Tailwind CSS.

В приложении нет аккаунтов, сессий, очередей, почты, файлового хранилища и фоновых задач.

Раскладка и введённая сумма сохраняются локально на устройстве. При смене
источника строки и сумма остаются на месте; подтверждённо неподдерживаемые
валюты недоступны для выбора базовой валютой. Ошибка загрузки каталога не
считается подтверждением отсутствия валюты. Сохранённый каталог используется
только для того же провайдера. Если хранилище устройства не позволяет запись,
приложение продолжает работать и сообщает, что изменения не сохранены.

## Избранные пары

Нажмите на звёздочку справа от строки конвертера, чтобы сохранить пару от текущей
базовой валюты к валюте строки (например, `USD → EUR`). Избранные пары появятся
над списком: нажатие на пару вернёт её в конвертер, а кнопка `×` удалит её из
избранного. Список хранится локально в браузерном хранилище этого устройства и
не синхронизируется между устройствами. Если выбранный провайдер больше не
поддерживает одну из валют пары, она остаётся в избранном, но временно недоступна.

## История конвертаций

Нажмите на значок часов в верхней панели и выберите «Сохранить текущий расчёт».
Запись содержит сумму, валюты, показанные результаты и время сохранения; хранятся
последние 50 сохранённых расчётов. При восстановлении в конвертер возвращаются
сумма и набор валют, а курс загружается заново — сохранённый результат в истории
не следует считать актуальной котировкой. История хранится локально на устройстве,
не отправляется на сервер и не синхронизируется между устройствами. Записи можно
удалять по одной или очистить историю целиком.

## Наборы валют

Под списком строк нажмите «Наборы валют» и выберите «Поездки», «Покупки» или
«Криптовалюты». Набор добавляет недостающие валюты к текущему списку, сохраняя
базовую валюту, сумму и существующие строки. Дубликаты не добавляются.
Перед применением видны валюты, недоступные у текущих источников: они пропускаются.
Курсы загружаются заново, а полученный список сохраняется локально, как обычная
раскладка конвертера. Состав наборов фиксирован и не означает рекомендацию покупки.

## Источники курсов

В нижней панели откройте настройки провайдеров, чтобы выбрать источник отдельно
для каталога валют, курсов, дневных изменений и графиков. Для дневных изменений
и графиков настройки разделены на фиат и криптовалюты: провайдеры поддерживают
разные типы данных. В автоматическом режиме приложение выбирает совместимый
источник по приоритету: НБРБ для фиатных курсов/истории, Kraken для crypto
rates/market data и crypto daily changes; CoinGecko доступен как альтернативный
источник и без ключа. Выбор сохраняется локально в базе данных этого
экземпляра приложения.
При ошибке выбранного вручную источника автоматического переключения на другой нет.
Если источник не ответил, приложение может использовать сохранённое значение.
Сохранённый официальный дневной курс НБРБ отмечается как «Источник не проверен»:
сбой запроса сам по себе не доказывает, что опубликованный курс устарел. Для
криптовалютного рыночного курса сохранённое значение помечается как устаревшее.
Для курса НБРБ показывается эффективная дата; при изменении даты приложение
проверяет API, пока источник не опубликует новую запись. Будущая дата курса
считается повреждённым ответом источника.

Сейчас доступны только встроенные источники. Для CoinGecko можно ввести Demo API
key в настройках провайдеров: приложение проверит ключ запросом к CoinGecko,
затем сохранит его зашифрованным в локальной базе приложения. Ключ не возвращается
через API приложения и передаётся CoinGecko в HTTP-заголовке. Конфигурация не
синхронизируется между устройствами. Пользовательские endpoint-адреса пока
не предусмотрены. Каталог может дополнительно использовать
метаданные других встроенных провайдеров для связи валют с их rate-adapters;
выбранный источник определяет, какие валюты входят в каталог.

Автоматический выбор учитывает приоритет, совместимость и наличие обязательного
ключа. Необязательный Demo key CoinGecko не является условием выбора этого API.
Настройки, курсы, дневные изменения и графики используют одну политику выбора.
При ручном выборе провайдера ошибки
показываются пользователю без автоматического переключения.
Доступное дневное изменение показывается рядом с кодом валюты в конвертере;
ошибка или отсутствие данных для этого показателя не мешает загрузке курсов.

Если каталог источника временно недоступен, приложение сохраняет раскладку и
показывает отдельное предупреждение. Последний успешный каталог того же источника
доступен до семи суток; каталог другого источника вместо него не подставляется.
Без сохранённого каталога API сообщает о недоступности, а не выдаёт неполный
список как успешный. Базовые фиатные валюты остаются доступны для конвертации.
Ограничение частоты запросов графика возвращается как 429 с `Retry-After`, если
источник сообщил время ожидания; это не ошибка отсутствия сети.

## Локальный запуск

```bash
composer install
npm install
php artisan migrate
```

Запусти процессы разработки в двух отдельных терминалах — обе команды остаются
работать в foreground.

Терминал 1 — Vite для frontend-ресурсов:

```bash
npm run dev
```

Терминал 2 — Laravel-сервер:

```bash
php artisan serve
```

После запуска открой адрес, который напечатает Laravel (обычно
`http://127.0.0.1:8000`). Не закрывай терминалы, пока работаешь с приложением.

Проверка:

```bash
php artisan test
npm run build
```

## Android release

NativePHP-команды выполняются из Windows PowerShell, не из WSL. Перед
сборкой перенеси значения из `.env.native-release.example` в локальный
`.env`. Пароли подписи и путь к keystore не хранятся в `.env` — передавай их
только через переменные текущей PowerShell-сессии.

`config/nativephp.php` удаляет из runtime bundle `APP_KEY` и Android signing
variables, а также исключает тестовые и локальные файлы. NativePHP создаёт
свой per-device application key при первом запуске.

После изменения версии или кода приложения собирай APK так:

```powershell
php artisan native:package android --output=.\builds
```

Перед распространением проверь, что в APK не находятся `APP_KEY`,
`ANDROID_KEYSTORE_*`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`, а в
manifest указаны ожидаемые название и версия.
